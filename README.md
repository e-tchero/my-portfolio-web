# Abdul-Hameed Aminu — Personal Portfolio

A responsive, recruiter-focused portfolio for **Abdul-Hameed Aminu**, a software developer and Advanced Diploma in Software Engineering (ADSE) student based in Abuja, Nigeria.

## Portfolio

- Live domain: https://abdulhameedamin.ct.ws/
- GitHub: https://github.com/e-tchero
- LinkedIn: https://www.linkedin.com/in/abdulhameed-amin/

## Features

- Premium editorial layout with a restrained neutral palette and warm accent.
- Automatic light/dark appearance using the visitor's operating-system preference.
- Responsive navigation and layouts for mobile, tablet, desktop, and wide screens.
- Reduced-motion support.
- Lenis smooth scrolling and GSAP reveal motion, loaded progressively with native-browser fallbacks.
- Project links, skills, education, and direct contact links.
- Search and social-sharing metadata.
- No database, contact-form backend, or server-side runtime required.

\`\`\`

\`\`\`bash

npm run preview
\`\`\`

The static deployment output is generated in \`dist/\`.

## Deploy to InfinityFree

1. Sign in to the hosting account that owns \`abdulhameedamin.ct.ws\`.
2. Open its File Manager or FTP details.
3. Back up the existing website files before replacing anything.
4. Open the domain's \`htdocs\` web root.
5. Upload the **contents of \`dist/\`** into \`htdocs\` (not the enclosing \`dist\` folder).
6. Confirm \`index.html\` and the \`assets/\` folder are directly inside \`htdocs\`.
7. Test the HTTPS domain on mobile and desktop.

The website is static; the hosting server does not need Node.js. Do not upload source files or \`node_modules\` to \`htdocs\`.

## Content accuracy

Project descriptions distinguish active development from completed implementation. Skills are presented as technologies encountered through study and project work, not as proficiency certifications. The portfolio intentionally launches without a personal photograph; a real headshot can be added later.

The contact section opens an email draft and links to GitHub and LinkedIn. It does not collect or store visitor messages.
